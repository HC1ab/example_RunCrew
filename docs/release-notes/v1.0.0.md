RunCrew 저장소의 첫 공식 릴리스입니다. 앱(Flutter) 개발에 앞서 **협업 기반, DORA 지표 수집 도구, CI/CD 파이프라인**을 갖췄습니다.

## ✨ 주요 기능

### 📊 DORA 4대 지표 자동 수집
- 배포 빈도, 리드 타임, 변경 실패율, 복구 시간(MTTR)을 GitHub API로 자동 계산 (#19, #22)
- Chart.js 대시보드: https://hc1ab.github.io/example_RunCrew/
- 지표 계산·수집 모듈 분리와 단위 테스트 35개, 커버리지 99% (#27)
- 지표 데이터는 `dora-metrics` 브랜치에 저장 (#46)

### ⚙️ CI/CD
- Lint → Test(Node 20/22/24 × Ubuntu/Windows/macOS) → Build(아티팩트) → Deploy → Notify (#31)
- Composite Action, Reusable Workflow, 변경 파일 감지로 필요한 job만 실행 (#33)
- 캐시 전략 실측 비교 리포트 (#34): 문서 전용 PR의 job 시간 −95.8%

### 🤝 협업
- PR 템플릿, CODEOWNERS, 기여 가이드, 리뷰 가이드(`[MUST]`/`[SHOULD]`/`[NITS]`), 행동 강령 (#25)
- 이슈 자동 응답, SLA 추적, 주간 요약 자동화 (#38, #41)
- main 브랜치 보호: PR 필수, `CI Result` 필수, merge commit만 허용

### 📚 문서
- ADR 6건 (#36, #46)
- OSS 라이선스 비교 분석, Inner Source 도입 로드맵 (#44)

## 🐛 수정
- Lead Time에 봇 커밋이 포함되던 문제 (incident #21, #22)
- DORA 수집 동시 실행 시 push 충돌 (#23)
- 지표 갱신 커밋만 제외하고 Dependabot 커밋은 포함 (#27 리뷰)
- main 실패 시 알림이 누락되던 문제 (#31 리뷰)
- 주간 요약의 머지된 PR 수가 0으로 표시되던 문제 (#40, #41)

## 📦 설치

git clone git@github.com:HC1ab/example_RunCrew.git
cd example_RunCrew
npm ci && npm test
